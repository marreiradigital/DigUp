Ignorar estes tipos de arquivo

O DigUp lê imagens, PDFs, documentos (txt, md, rtf, docx, odt, html), áudio e vídeo. Chaves, certificados e arquivos de senha nunca são lidos, nem as pastas ocultas.

O DigUp acha código pelo que ele faz. Digite “code:” no painel de busca e diga o que o código faz, ou escolha Código na janela. Os resultados abrem no seu editor, na linha certa.

Pastas de código

Abrir o código em

O DigUp lê o que o git versiona nessas pastas: código-fonte, configuração, a documentação do repositório e notebooks. Deixa de fora o que o git ignora, dependências e resultado de build, arquivos de dados, chaves e arquivos de senha. O código tem um índice próprio e só aparece quando você busca por código.

Privacidade

O DigUp lê as pastas que você escolhe e guarda o que aprende no seu índice, neste computador. Ele só se conecta à internet para baixar o modelo, uma vez, e para verificar atualizações (em Geral), o que não envia nada sobre os seus arquivos.
